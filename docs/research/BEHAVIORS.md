# Studio and Pricing Behaviors

## Studio

- Starter visual hover: border brightens, image lifts slightly, and its prompt label becomes visible.
- Starter visual click: switches the active media type and fills the composer prompt.
- Media switch: updates the available model and aspect-ratio options.
- Generate: preserves the existing precheck, generation, polling, result and recent-assets invalidation flow.
- Responsive: the empty-state collage compresses on mobile; composer controls wrap into full-width rows and the primary action remains reachable.

## Pricing

- Cards lift slightly on hover without changing layout.
- CTA icon capsule slides subtly on hover, matching PromptWise's long pill-button behavior.
- Mobile uses horizontal snap cards with one card predominantly visible.
- Existing unauthenticated login handoff and authenticated ZPay payment choice remain unchanged.
