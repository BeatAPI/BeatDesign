# Studio and Pricing Reference Topology

## Studio

1. Product top bar supplied by `ProductPageShell`.
2. Full-height black creation stage with no persistent sidebar.
3. Centered BeatAPI empty state:
   - four overlapping square visual references;
   - short “Start here” title and one-line instruction;
   - each visual is a clickable prompt starting point.
4. Generated result replaces the empty state.
5. Wide rounded composer floats at the bottom:
   - prompt editor first;
   - media, model and aspect controls in one toolbar;
   - credits and square generate action at the far right.

Interaction model: click-driven media/model/ratio controls, click-driven starter ideas, asynchronous generation state.

## Pricing

1. Floating rounded PromptWise-style navigation shell.
2. Centered large headline and compact subtitle.
3. Rounded billing-mode capsule.
4. Four responsive package cards:
   - savings ribbon behind the card body;
   - 38px rounded plan body;
   - plan name and discount badge;
   - large price row;
   - inset credits/value panel;
   - full-width pill CTA with a separate leading icon capsule;
   - benefit list.
5. Compact legal/value footer.

Interaction model: horizontal snap carousel on mobile, static multi-column grid on larger screens, existing sign-in and checkout actions.
