# Code of conduct

We want BeatAPI Workspace to be a welcoming, constructive open-source project.

Contributors and maintainers must communicate respectfully, focus criticism on the work, accept good-faith feedback, and avoid harassment, discrimination, threats, doxxing, or publishing private information without permission.

Project maintainers may edit or remove contributions and restrict participation when behavior harms the community. Report conduct concerns privately through the repository maintainers or GitHub's reporting tools. Maintainers will review reports fairly and protect reporter privacy where practical.

This policy applies in repository discussions, pull requests, issues, and other spaces where someone is representing the project.
